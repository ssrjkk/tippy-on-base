# Security Policy

Tippy moves real money: USDC on Base, held in a custodial hot wallet by design.

## Reporting a vulnerability

**Do not open a public GitHub issue for a security problem.**

1. Telegram: [@ssrjkk](https://t.me/ssrjkk)
2. X / Twitter: [@ludych1](https://x.com/ludych1) (DMs open)

Send the affected component, reproduction steps, an impact assessment and any
proof-of-concept. Please give us reasonable time to patch before public
disclosure; reporters are credited in the release notes unless anonymity is
requested.

The full policy - scope, the fund-safety paths we care about most, and the
acknowledgement and fix timelines - is in
[docs/SECURITY.md](docs/SECURITY.md).
